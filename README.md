# 藏在日常裡的情書

暖白手帳風的情侶互動日記，透過 15 個問題，把心裡話寫給彼此。

- 一題一頁，搭配手繪插畫、翻頁動畫與輕柔背景音樂。
- 完成後可開啟 Gmail 撰寫信件，由使用者親手寄出。
- 可將完整回答匯出為日記 PNG，或下載全部圖片 ZIP，自行傳到 LINE。
- 姓名、信箱與回答只保留在目前頁面的記憶體；圖片在裝置上生成。
- 這份 GitHub Pages 版本的全站完成計數暫未啟用。

網站程式、字型、插畫、CSS 與 JavaScript 全部內嵌在 index.html。

GitHub Pages 發布設定：Deploy from a branch → main → / (root)。
